1. HTTP y la web
Un usuario reporta: «la página carga, pero las imágenes salen rotas»
. En DevTools → pestaña Network, laspeticiones de las imágenes muestran el estado 404.

(a) ¿Qué significa exactamente ese 404 ? ¿El problema está del lado del cliente o del servidor? 
Justifica.

R/: El código 404 significa que el servidor recibió la petición pero no encontró el recurso solicitado. 
El error está del lado del servidor o de la ruta configurada, no por parte del cliente.

(b) ¿Qué dato de la petición fallida revisarías primero para encontrar la causa, y con qué lo 
compararías?

R/: Se debe revisar primero el URL de la petición fallida en DevTools y compararlo con la ruta real 
del archivo en el servidor y con la ruta escrita en el HTML/CSS.

2. HTML semántico
Reescribe este fragmento con las etiquetas semánticas correctas y justifica dos de tus decisiones.

Código:
<div class="top"><div class="logo">Mi blog</div></div>
<div class="links"> ...</div>
<div class="post"><div class="titulo-grande">Mi viaje</div><p>...</p></div>

Código corregido:
<header><h1>Mi blog</h1></header>
<nav>...</nav>
<article><h2>Mi viaje</h2><p>...</p></article>

Justificaciones:

1. El título principal lo agregue en un <h1> y dentro de <header>.
2. Los enlaces de navegación los agregue en <nav>.

5. Una grilla de productos debe mostrar 1 columna en el celular y hasta 4 en escritorio. 
Dos estudiantes proponen:  Flexbox vs Grid

Propuesta A (Flexbox):
.grilla { display: flex; flex-wrap: wrap; gap: 16px; }
.tarjeta { flex: 1 1 250px; }

Propuesta B (Grid):
.grilla { display: grid; gap: 16px;
grid-template-columns: repeat(auto-fit, minmax(250px, 1fr)); }

(a) ¿En qué situación visible se comportan distinto las dos propuestas? Descríbela (puedes dibujarla). 
R/: Diferencia visible: Flexbox puede dejar filas desalineadas. Grid mantiene columnas uniformes.

(b)¿Cuál usarías para una grilla uniforme de tarjetas y por qué?
R/: Para grilla uniforme: Usaria Grid, porque este garantizaria la consistencia y mejor control responsive.
